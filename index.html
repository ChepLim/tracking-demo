Trang Demo Tracking GTM

Trang này dùng để kiểm tra debug mode của Google Tag Manager container ID: GTM-TW8Q3XGZ

1. Test Click (Nút bấm)

Thử nghiệm tracking hành vi bấm nút.



Dùng để test Trigger loại "Click - All Elements".

2. Test Link (Liên kết ngoài)

Bấm vào link này để test tracking chuyển trang.

Đến trang Google.com

Dùng để test Trigger loại "Click - Just Links".

3. Test Form Submit

Điền email giả và bấm đăng ký.

Dùng để test Trigger loại "Form Submission" (Form ID: newsletter-form).

4. Test Data Layer (Nâng cao)

Nút này sẽ đẩy một sự kiện tùy chỉnh (Custom Event) vào DataLayer.

Dùng để test Trigger loại "Custom Event" với Event Name là "generate_lead".
